# LLM API Cost Calculator 🧮

A free, open-source, bilingual web tool to calculate and compare your LLM API costs. 

Instead of guessing how much your multi-model routing will cost at the end of the month, use this tool to instantly calculate the price gap between official API pricing (OpenAI, Anthropic, Google) and aggregated routing platforms.

## 🚀 Live Demo
Try it out here without any sign-up: **[Live Calculator](https://llm-api-cost-calculator.vercel.app/)**

## ✨ Features
- **Bilingual Support:** Seamless toggle between English and Chinese.
- **Wide Model Coverage:** Includes Azure-GPT, Claude-Max, Gemini-Ultra, Gemini-Flash, and major domestic Chinese models (like DeepSeek/Qwen).
- **Instant Calculation:** No backend required, zero latency. Input your token volume and see the cost breakdown immediately.
- **Image Generation:** Special billing logic for image models (DALL-E / MJ).

## 🛠️ Tech Stack
- Pure HTML, CSS, and Vanilla JavaScript.
- Single-file architecture, no build tools required.
- Hosted on Vercel.

## 💻 How to run locally
1. Clone this repo: `git clone https://github.com/xyall1314-max/llm-api-cost-calculator.git`
2. Open `index.html` in any browser. That's it!
